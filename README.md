## 🌐 Project 3 — Basic Node.js Web Server

**Tech:** Node.js built-in `http` module (zero external dependencies)

### Features
- ✅ GET `/` — HTML home page
- ✅ GET `/about` — About page
- ✅ GET `/api/info` — JSON server info (version, uptime, memory)
- ✅ GET `/api/time` — JSON current server time
- ✅ POST `/api/echo` — Echoes JSON body back
- ✅ Static file serving from `/public` directory
- ✅ Custom 404 and 500 error pages
- ✅ CORS headers on all API responses
- ✅ Request logging with timestamps
- ✅ Graceful shutdown (SIGINT/SIGTERM)

### How to Run
```bash
cd project3-node-server
node server.js
```
Open http://localhost:3000
